# WWF WrestleMania 2000: Recompiled (bootstrap)

Native PC port of WWF WrestleMania 2000 (N64) via
[N64Recomp](https://github.com/N64Recomp/N64Recomp) static recompilation, running
on N64ModernRuntime (ultramodern + librecomp) with RT64 as the renderer. Third
project in the AKI-engine recomp family, following WCW vs. nWo World Tour:
Recompiled and WCW/nWo Revenge: Recompiled — see those projects for the shared
architecture and build documentation.

Not an emulator, not a decompilation. No game assets are distributed; you supply
your own ROM (USA, V1.2).

Status: early bootstrap — the game recompiles; port bring-up is in progress.
